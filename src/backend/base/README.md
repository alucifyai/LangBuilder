# Langflow Base

Core backend package for Langflow - a visual framework for building language model applications.

## Overview

This package contains the core functionality for the Langflow backend, including:
- Database models and ORM (SQLModel)
- FastAPI application and API endpoints
- Authentication and authorization services
- Component library for LangChain
- Graph execution engine

## Installation

This package is typically installed as part of the main Langflow package.
