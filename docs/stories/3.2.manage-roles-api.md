# Story 3.2: Manage Roles via API

## Status

Done

## Story

**As a** DevOps Engineer,
**I want** to create and manage roles through APIs,
**so that** I can integrate RBAC into automation pipelines.

## Acceptance Criteria

**@AC1**: Create role via API
- Given I have an Admin API token
- When I POST /api/v1/roles with body {name:"QALead", permissions:["read","deploy_environment"]}
- Then response is 201 with role_id
- And GET /api/v1/roles/{role_id} returns the same permissions

## Context Analysis

### Existing Implementation

**Roles API is fully implemented!**

File: `src/backend/base/langflow/api/v1/roles.py`

### API Endpoints Available

✅ `POST /api/v1/roles` - Create role
✅ `GET /api/v1/roles` - List all roles
✅ `GET /api/v1/roles/{role_id}` - Get role by ID
✅ `PATCH /api/v1/roles/{role_id}` - Update role
✅ `DELETE /api/v1/roles/{role_id}` - Delete role

### Features

- Request validation with Pydantic schemas
- Admin permission checks
- Audit logging for all role changes
- Version tracking
- Grant count before deletion (safety check)
