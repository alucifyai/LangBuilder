# Story 4.1: Deny by Default

## Status

Done

## Story

**As a** Security Engineer,
**I want** actions denied unless explicitly permitted,
**so that** no unintended access is granted.

## Context Analysis

**Deny-by-default is implemented in permission evaluation!**

File: `src/backend/base/langflow/services/auth/permissions.py`

The `check_permission()` function:
1. Gets all user grants (direct + via groups)
2. Checks if any grant has the required permission
3. Returns `False` if no matching grant found (deny by default)

Implementation:
```python
async def check_permission(...) -> bool:
    # Get grants
    grants = await get_user_grants(db, user)
    
    # Check each grant
    for grant in grants:
        if has_permission:
            return True  # Explicit allow
    
    return False  # Default deny
```

All acceptance criteria met:
✅ AC1: Users with no roles are denied access (returns False)
